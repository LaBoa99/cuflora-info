/flora-mapsListar mapas

+

Mapas de flora: una ortofoto georreferenciada con sus zonas.

Tipo
Lista paginada
Permiso

Parámetros

pageSizeconsulta · integerRegistros por página. Con llave, máximo 100.
Includes · in.<relación>=true
in.placements=truein.plants=truein.zones=truein.placement_points=truein.polygons=truein.children_zones=true

Archivo CSV · 10 por hora por llave
Permiso

Parámetros
idruta · number Obligatorio.
groupByconsulta · string
Respuesta 200 · text/csv · ejemplo

12,Agave tequilana,Agave azul,…
curl
curl -H "Authorization: Bearer $CUFLORA_KEY" \
  "https://cuflora.kawi.page/flora-maps/1/export" \
  -o cuflora.csv
Python
import os, requests

r = requests.get("https://cuflora.kawi.page/flora-maps/1/export",
                 headers={"Authorization": f"Bearer {os.environ['CUFLORA_KEY']}"})
r.raise_for_status()
open("cuflora.csv", "wb").write(r.content)
JavaScript
const r = await fetch("https://cuflora.kawi.page/flora-maps/1/export", {
