/reports/exportExportar reportes a CSV

+

Reportes en un CSV. Filtra por planta (subjectId) y por día (from, to, en formato AAAA-MM-DD, incluidos).

Tipo
Archivo CSV · 10 por hora por llave
Permiso
reports:export
Parámetros
subjectIdconsulta · número
reporterIdconsulta · número
fromconsulta · texto
toconsulta · texto
Respuesta 200 · text/csv · ejemplo
id,fecha,categoria,subtipo,planta,…
curl
curl -H "Authorization: Bearer $CUFLORA_KEY" \
  "https://cuflora.kawi.page/reports/export" \
  -o cuflora.csv
Python
import os, requests

r = requests.get("https://cuflora.kawi.page/reports/export",
                 headers={"Authorization": f"Bearer {os.environ['CUFLORA_KEY']}"})
r.raise_for_status()
open("cuflora.csv", "wb").write(r.content)
JavaScript
const r = await fetch("https://cuflora.kawi.page/reports/export", {
  headers: { Authorization: `Bearer ${process.env.CUFLORA_KEY}` },
});
if (!r.ok) throw new Error(`HTTP ${r.status}`);
