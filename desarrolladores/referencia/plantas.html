/plants/exportExportar plantas a CSV

+

Todas las plantas en un CSV (UTF-8 con BOM, separado por comas). Se puede agrupar y filtrar por especie, género o familia.

Tipo
Archivo CSV · 10 por hora por llave
Permiso
plants:export
Parámetros
groupByconsulta · string
speciesIdconsulta · number
genusIdconsulta · number
familyIdconsulta · number
searchconsulta · string
Respuesta 200 · text/csv · ejemplo
id,nombre_cientifico,nombre_comun,especie,genero,familia,zona,latitud,longitud
12,Agave tequilana,Agave azul,…
curl
curl -H "Authorization: Bearer $CUFLORA_KEY" \
  "https://cuflora.kawi.page/plants/export" \
  -o cuflora.csv
Python
import os, requests

r = requests.get("https://cuflora.kawi.page/plants/export",
                 headers={"Authorization": f"Bearer {os.environ['CUFLORA_KEY']}"})
r.raise_for_status()
open("cuflora.csv", "wb").write(r.content)
JavaScript
const r = await fetch("https://cuflora.kawi.page/plants/export", {
  headers: { Authorization: `Bearer ${process.env.CUFLORA_KEY}` },
});
if (!r.ok) throw new Error(`HTTP ${r.status}`);
const csv = await r.text();
